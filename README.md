
# AI Systems Labs — Computer Vision & OCR

Приложение на **C# / .NET 8**, объединяющее лабораторные работы по дисциплине «Системы искусственного интеллекта».

Разработано в 2025 году в рамках обучения по направлению **09.03.01 «Информатика и вычислительная техника»** в МГТУ «СТАНКИН».

Проект посвящён практическому применению алгоритмов компьютерного зрения, обработки изображений и оптического распознавания текста.

## Функциональность

Приложение содержит три независимых модуля, объединённых общим графическим интерфейсом Windows Forms.

### 1. Обнаружение лиц и глаз

- Захват видеопотока с веб-камеры.
- Обнаружение лиц и глаз с помощью каскадов Хаара.
- Визуализация обнаруженных объектов в реальном времени.
- Управление запуском и остановкой камеры.

**Технологии:** Emgu CV, OpenCV, Haar Cascades.

### 2. Поиск объектов на изображениях

- Обнаружение ключевых точек и вычисление дескрипторов алгоритмом ORB.
- Сопоставление дескрипторов с использованием BFMatcher.
- Фильтрация соответствий методом Lowe's Ratio Test.
- Оценка гомографии с помощью RANSAC.
- Поиск объектов с использованием Template Matching при недостаточном количестве надёжных соответствий.
- Визуализация ключевых точек, соответствий и найденных объектов.

**Технологии:** Emgu CV, ORB, BFMatcher, RANSAC, Template Matching.

### 3. Оптическое распознавание текста (OCR)

- Загрузка изображений для распознавания текста.
- Поддержка русского и английского языков.
- Предварительная обработка изображений: перевод в оттенки серого, бинаризация методом Оцу и масштабирование.
- Выделение произвольной области изображения для распознавания.
- Отображение распознанного текста и показателя уверенности OCR.
- Сохранение результатов в текстовый файл.

**Технологии:** Tesseract OCR, Emgu CV.

AIsystems_labs/
├── MainForm.cs
├── IModule.cs

## Запуск

**Требования:**
- Windows;
- .NET 8 SDK;
- веб-камера для первого модуля.

Клонировать репозиторий:

```bash
git clone https://github.com/EsweltyLefenro/AIsystems_labs.git
cd AIsystems_labs
```

Запустить приложение:

```bash
dotnet run --project AIsystems_labs/AIsystems_labs.csproj
```

Зависимости NuGet восстанавливаются автоматически. Данные для Tesseract OCR и XML-файлы каскадов Хаара включены в проект.

## Статус проекта

Учебный проект, разработанный для практического изучения алгоритмов компьютерного зрения и распознавания изображений.

Приложение демонстрирует интеграцию существующих библиотек и алгоритмов в единое настольное ПО. Проект не предполагает обучения собственных нейросетевых моделей.
